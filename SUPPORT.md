# Getting help

- **Using the app**: the [user guide](docs/GUIDE.md) covers the library, reading statuses,
  shelves, imports and exports (in French for now). The app has its own FAQ in
  *Settings → Having trouble?*.
- **Found a bug, or want a feature?** Open an
  [issue](https://github.com/zelytra/Librarius/issues/new/choose) using one of the templates.
- **Running or developing Librarius**: start with the [developer wiki](docs/wiki/Home.md),
  then [Running locally](docs/wiki/Running-Locally.md).
- **A security problem?** Never in public: see [SECURITY.md](SECURITY.md).

Librarius is a personal project maintained in spare time. Answers can take a few days.
